# Классификация текста: BERT vs TF-IDF + Logistic Regression

## 📌 О проекте

Проект посвящён задаче классификации текстов (отзывы IMDb).

Сравниваются два подхода:
- классический ML (TF-IDF + Logistic Regression)
- глубокое обучение (BERT)

Цель — показать разницу между традиционными и современными методами NLP.

## 📊 Результат

Проведено сравнение двух подходов к классификации текста.

- Logistic Regression — быстрый базовый результат  
- BERT — более мощный подход при достаточном обучении
