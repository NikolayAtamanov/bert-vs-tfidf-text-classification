# Классификация текста: BERT vs TF-IDF + Logistic Regression

## 📌 О проекте

Проект посвящён задаче классификации тональности текста на примере датасета отзывов IMDb (25 000 отзывов, бинарная классификация: позитив/негатив).

Сравниваются два подхода:
- классический ML (TF-IDF + Logistic Regression)
- глубокое обучение (BERT, дообучение bert-base-uncased)

Цель — показать разницу между традиционными и современными методами NLP, оценить, насколько трансформерная модель превосходит классический baseline при ограниченных вычислительных ресурсах.

## 📊 Результат

| Модель | Accuracy | Precision | Recall | F1-score |
|--------|----------|-----------|--------|----------|
| Logistic Regression | 0.88 | 0.88 | 0.88 | 0.88 |
| BERT | 0.85 | 0.83 | 0.875 | 0.85 |

Logistic Regression обучена и протестирована на полном датасете (25 000 отзывов). BERT дообучен на уменьшенной подвыборке (5 000 train / 1 000 test) за 1 эпоху — при этом показывает более высокий recall (0.875), но чуть уступает по общей accuracy (0.85 против 0.88), что объясняется значительно меньшим объёмом обучающих данных и всего одной эпохой обучения. При обучении на полном датасете и большем числе эпох BERT ожидаемо превзошёл бы классический baseline.

## 🧠 Вывод

Проект показывает разницу между классическим ML и трансформерными моделями в задаче NLP-классификации: TF-IDF + Logistic Regression даёт быстрый и стабильный baseline, а BERT способен уловить более тонкий контекст текста за счёт self-attention, но требует больше данных и вычислительных ресурсов для раскрытия потенциала.
